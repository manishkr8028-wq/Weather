# Weather Dashboard

A real-time Weather Dashboard built using HTML, CSS, and JavaScript.

## Features
- Search weather by city name
- Real-time weather data using OpenWeather API
- Asynchronous JavaScript with async/await
- Fetch API and JSON processing
- Error handling for invalid cities and failed requests
- Responsive user interface

## Setup
1. Get an API key from OpenWeather.
2. Open `script.js`.
3. Replace `PASTE_YOUR_API_KEY_HERE` with your API key.
4. Open `index.html` using Live Server.

## Technologies
- HTML5
- CSS3
- JavaScript
- REST API
- Fetch API
